# Стартовый промпт для реализации AgentO Core

Скопируй целиком и вставь в новую сессию.

---

Реализуй проект **AgentO Core** по подготовленной документации.

## Документация

- Спецификация: `docs/features/agento-core/spec.md` — прочитай перед началом
- План: `docs/features/agento-core/plan.md` — следуй порядку блоков, секциям «Стратегия выполнения» и «Ревью после каждого шага»
- Чеклист: `docs/features/agento-core/checklist.md` — отмечай прогресс

## Инструкции

1. Прочитай `spec.md`, `plan.md` и `checklist.md` целиком перед началом работы.
2. Работа ведётся в ветке `main` — отдельную feature-ветку не создавай.
3. Отметь в checklist.md пункты «Подготовка» как выполненные.
4. Выполняй задачи согласно **стратегии выполнения** из plan.md:
   - Блоки 1–2 строго последовательно (фундамент)
   - Блок 3 (задачи 5, 6) — параллельно субагентам после задачи 4
   - Блок 4: задача 7 сначала, затем задачи 8 и 9 параллельно субагентам
   - Блок 5 (задачи 10, 11) — параллельно в одной сессии после 7, 8, 9
   - Блоки 6 и 7 — максимальный параллелизм субагентами после блока 5; в блоке 7 задача 16 первой, затем 17-20 параллельно
   - Блок 8 — строго после всего
5. После **каждой задачи**: сверка с plan.md и spec.md; убедись что нет конфликта с параллельными задачами. Если задачу делал субагент — проверь результат перед следующим шагом.
6. После выполнения задачи — отметь её в checklist.md (`[x]`).
7. Запусти указанную для задачи проверку из колонки «Проверка» в таблице plan.md.
8. Коммить после каждого завершённого блока задач.
9. По завершении всех задач — отметь «Финализация» в checklist.md и обнови **Статус** в README.md на `Done`.
10. Если что-то непонятно — спроси, не додумывай.

## Стек

- TypeScript (strict) + Node.js ≥ 18 + ESM
- TUI: Ink 4.x + React 18
- Валидация: Zod
- CLI-парсинг: Commander или Yargs
- Тесты: Vitest
