## Краткое описание

npm-пакет AgentO — сервис с TUI-интерфейсом для запуска CLI ИИ-агентов (Claude Code, OpenCode и другие) с кастомными настройками API-провайдеров. Управляет конфигами агентов (создание/редактирование/восстановление) и поддерживает несколько режимов запуска.
